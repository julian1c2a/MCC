# MCC

Repositorio de documentación: HTML, Markdown y LaTeX (con herramientas de dibujo asociadas).

## Estructura

- `html/` — documentos y fragmentos HTML.
- `markdown/` — documentación en Markdown.
- `latex/` — documentos LaTeX (`.tex`), estilos y bibliografía.
- `figuras/` — figuras y diagramas (TikZ, draw.io/diagrams.net, imágenes exportadas).

## Entorno LaTeX

- TeX Live (MSYS2 UCRT64): `/c/msys64/ucrt64/`
- MiKTeX: `/d/miktex/`

## Futuro

En segundo plano, este repositorio también podrá incluir scripts de apoyo en Python y JavaScript, y algún entorno científico (Jupyter/notebooks) para generación o procesamiento de la documentación.
